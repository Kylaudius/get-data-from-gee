# 县城与大城市的财政分轨研究

财政收支、人口普查与遥感公共空间的全国县级叠加研究。

## 文件管理规则

大的结构性变化建新的大版本文件夹（v1、v2…），小的修改在大版本内建小版本文件夹（v1.0、v1.1…）。每个小版本内按 报告、附录、数据、代码、图表、外部参数 六类存放文件，并附 `readme.md` 记录本次修改了什么、为什么修改、思路是什么。开新版本前运行 `代码/tools/check_manual_edits.py --check`，检查研究者对上一版的手动修改，避免新构建覆盖它们。

原始数据、中间数据与结果数据不纳入 Git 版本库（见 `.gitignore`），只保存在研究者本机。
