## 为什么这样设计

**命题的修正。** 文献核验显示原命题有两处需要修正。其一，大城市并非单纯依靠市场，而是国家主导、借用土地与住房市场工具的国家企业家主义体制 (F. Wu, 2018)。其二，县城的建设资金除转移支付外还有城投债务 (Z. Li et al., 2024)，转移支付也可能被人员经费吸收 (Guo, 2008)，因此设立对立假说 R1。概念框架改用财政来源、国家中心性与人口流动三个维度。

**分析单元。** 《中国县域统计年鉴》只收录部分市辖区，区级财政没有全国统一的公开数据，所以大城市一侧以地级市的市辖区合计为单元，与《中国城市统计年鉴》口径对应；县与县级市各为一个单元。遥感指标在每个单元的中心建成区内统计，避免县域林地与农田虚增县城绿地。

**财政年份。** 2020 年抗疫特别国债与新增赤字各 1 万亿元经特殊转移支付直达市县，主分析期因此取 2018、2019、2021 三年均值。

**人口分母。** 住建部人均公园绿地面积以户籍人口加暂住人口为分母，会低估人口流出县城、高估人口流入大城市的人均值，恰好削弱原命题，所以一律改用普查常住人口，并以普查重标定格网人口。

**绿地口径。** WorldCover 的草地类精度只有 34% (Venter et al., 2022)，以树木为主口径；主指标采用人口加权绿地暴露 (B. Chen et al., 2022b)。公园与绿道没有全国遥感产品，本版构造了连片绿地斑块、滨水绿带与道路两侧绿带三个代理，并在报告中写明它们是代理。

**识别。** 截面只作条件相关。因果识别以撤县设区为首选准实验，连片特困地区边界断点差分为次选，省直管县为对称检验，估计量采用交错处理稳健的 Callaway–Sant'Anna 与 Sun–Abraham 方法。

## 与研究者要求的差异

1. 研究者要求用 Chrome 打开 DOI 核验文献。本次运行环境的网络策略阻断了 doi.org、出版社网站和国家统计局等官方网站，改用 Scite 的 Crossref 元数据与摘要逐条核对 DOI，并用检索摘要核对官方数据口径。附录 A 与附录 B 中写明了这一点，投稿前请在浏览器中逐条打开 DOI 复核。
2. 研究者原话中说“像这种一样”，但本次对话中没有看到附图或链接。本版按常见的“人均财政支出 × 人口变化”全国叠加图理解，图 fig1 的双变量地图即对应这一形式。下一次迭代请提供参考图，以便对齐。
3. 附录 A 中五条 Nature Communications、Scientific Data 等期刊的文章编号未能通过 Scite 取得，暂缺，投稿前补全。
