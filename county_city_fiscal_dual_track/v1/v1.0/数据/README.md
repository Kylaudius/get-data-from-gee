# 数据文件夹说明（v1.0）

`数据/原始/`、`数据/中间/`、`数据/结果/` 三个文件夹不纳入 Git 版本库（统计年鉴数据有版权，体积也大），只保存在你的电脑上。`数据/模板/` 中的 CSV 规定了每类原始数据的列名，整理原始数据时照模板填写即可。文件一律保存为 UTF-8 编码的 CSV（Excel 中选择“CSV UTF-8（逗号分隔）”），GBK 编码的 CSV 脚本也能自动识别。

## 2 整理要点

**年份。** 年鉴年份比数据年份晚一年，《中国县域统计年鉴 2020》报告的是 2019 年数据。模板中的 `year` 一律填数据年份。主分析需要 2018、2019、2021 三年，2010 期需要 2009、2010、2011 三年，可在 `外部参数/config.yaml` 修改。

**单位。** 财政金额按年鉴原单位（通常为万元）填写，并在 config.yaml 的 `money_unit_in_raw` 注明；户籍人口按万人填写。普查人口按人填写，比例填 0 至 1 的小数。

**代码。** 一律使用 6 位行政区划代码。市辖区财政表的 `pref_code` 填地级市代码（例如 4401 开头的城市填 440100），直辖市填 110000、120000、310000、500000。`scope` 列填“市辖区”；同一张表里若也录了“全市”口径，脚本只使用市辖区口径的行。

**户籍人口。** 七普分县资料表 1 不含户籍人口，2020 年户籍人口从县域统计年鉴的年末户籍人口填入 `fiscal_county.csv` 的 `pop_hukou_yearend`。2010 年普查表 1 含户籍人口，可填入普查表的 `pop_hukou`。

**住房变量。** 七普分县资料表 8 为家庭户住房状况。若国家版没有按住房来源分类的分县户数，从各省普查年鉴的“各地区按住房来源分的家庭户户数”表整理，换算为比例后填入。长表为 10% 抽样，小县的比例误差较大。

**代码对照表。** 按民政部 xzqh.mca.gov.cn 的逐年变更情况整理：旧代码、旧名称、新代码、新名称、变更年份、变更类型、权重。普通更名或整体并入填权重 1；一个旧单位拆入多个新单位时，按面积或人口比例填权重，同一旧代码同一年份各行的权重之和应为 1。若只是部分乡镇划出、原代码继续保留，写两行：旧代码 → 旧代码（保留比例）与 旧代码 → 接收单位代码（划出比例）。脚本只对数据年份之后发生的变更做映射，并按变更年份先后处理多次连续变更。

## 3 检查

运行 `02_build_fiscal_census.py` 后，打开 `数据/中间/panel/qa_report.md`，查看未匹配代码、重复记录和缺失数量。未匹配的旧代码补进代码对照表后重新运行即可。
